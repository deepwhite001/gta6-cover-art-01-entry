Neon Coast is an offline cover maker that turns your photos into a multi-panel poster: one photo (or two) cut into panels under a hand-painted sunset sky — sun, skyline and palm silhouettes drawn in code — with a big outlined title and a tagline. Pick from three panel layouts (Poster, Four panels, Three strips), three colour grades (Sunset, Neon night, Teal dawn) and three post sizes (1080 x 1080, 1080 x 1350, 1920 x 1080), crop and pan each photo with sliders, then download the cover as a PNG. Everything runs from the static files in `app/` — no network requests, no fonts to fetch, no Rockstar art or logos anywhere.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
