Neon Coast is an offline cover studio that turns two of your photos into a GTA-style poster: a hand-painted Vice City dusk — gradient sky, a sun that hangs clear above the rooftops, lit towers and palm silhouettes, all drawn in code — with your photos cut into panels and a big outlined title over a caption band. Choose one of three panel layouts (Poster, Four panels, Three strips), one of three colour grades (Sunset, Neon night, Teal dawn) and one of three post sizes (1080 x 1080, 1080 x 1350, 1920 x 1080), frame each photo with zoom and pan sliders, then download the cover as a PNG. Everything runs from the static files in `app/` — no network requests, no fonts to fetch, no Rockstar logos or artwork anywhere.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
